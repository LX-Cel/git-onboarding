# 0.2.0-preview.3 · 系统 Git 练习与综合实战

Windows x64 私有预览版，包含 62 个单元：61 门判题课程、122 个引导/挑战场景，以及两个独立自由实验工作区。

## 这一版能练什么

- rebase、交互整理、onto/autosquash、cherry-pick、冲突继续与取消、stash/reflog、三种 reset。
- origin/upstream 双远端 Fork → 功能分支 → PR → 评审修改 → 检查 → 合并与同步；包含冲突、保护规则和 Merge/Squash/Rebase 策略。
- 初始化/克隆、跟踪分支、三种 pull、推送拒绝、明确租约、远端修复。
- worktree、bisect、标签、patch/am、bundle、子模块、稀疏检出、浅克隆、换行属性、fsck/gc 恢复。
- 真实 SSH 提交与标签签名、LFS 提交与历史迁移、假凭据历史清理。
- 新增凭据失效、令牌写权限、多账号路径选择及只读上游/Fork 推送诊断。
- 新增入职交接、发布回滚、并发协作、遗留排错综合任务；草稿、队友提交和原发布证据都有明确保留要求。
- 自由实验区提供完整终端、双远端和队友仓库；没有固定通关条件，关闭后保留实验，重置前需确认。

沿用 Fluent 2 工作台；手动检查会显示本次结果与仓库记录。克隆后编辑器优先打开当前任务文件。

## 安装和升级

下载 `Git-Onboarding-0.2.0-preview.3-Setup.exe`，关闭旧应用后安装到原目录，无需先卸载。启动后如提示更新，选择「保留练习并更新」，保留练习文件、提交历史、暂存区及学习进度。

首次使用需 Windows WSL 2。镜像和扩展工具已随安装包提供，日常练习无需外网。仓库保持私有，下载需有访问权限的 GitHub 账号；安装包未代码签名，附件 SHA256 文件可校验完整性。

## 验证与边界

1257 项真实 Git 断言、6 项 Node 测试、6 类工具归档拒绝检查，以及隔离、真实 PTY、6 次 HTTP 服务启停/重连均通过。旧 0.1.0 镜像升级验证提交、暂存区、工作区和进度保留。交互式 rebase 另在真实 nano 中完成清单修改、保存、退出和判题。依赖审计未发现已知漏洞。

安装包大小 169,865,571 字节，SHA256：`b57630c583f6909dc7c09333a390bcbef6fddd5c8f158199e0e0c334080309da`。

Fork/PR 是离线教学托管流程，认证课程使用本地 HTTP 与假凭据，不连接个人 GitHub，不模拟企业 SSO 或 TLS。签名使用练习专用密钥；历史清理使用假凭据。本版覆盖已列出的核心与综合工作流，有限课程不等于穷尽全部 Git 扩展和平台差异。
