# 0.2.0-preview.2 · 53 门 Git 课程

Windows x64 私有预览版，包含 53 门课程、106 个引导/挑战场景，沿用 Fluent 2 工作台。相较 preview.1 新增 20 门课程。

- PR 评审期间的上游冲突、Squash/Rebase 合并、受保护主线与必需检查。
- 仓库初始化与身份配置、clone 和分支跟踪、三种 pull 策略、merge/am 中断恢复。
- 分离 HEAD、误删分支、blame/log 定位、跨平台换行、fsck/gc 对象恢复。
- 真实 SSH 提交与标签签名、LFS 文件提交与历史迁移、假凭据历史清理。
- 内置离线工具更新；重置练习时终端等待新会话就绪后才开放输入。

## 安装和升级

下载 `Git-Onboarding-0.2.0-preview.2-Setup.exe`，关闭旧应用后安装到原目录，无需先卸载。启动后若提示更新，选择「保留练习并更新」。更新课程和内置练习工具时保留原练习文件、Git 提交、暂存区及学习进度。

首次使用需 Windows WSL 2，安装包包含练习镜像和离线工具；日常练习不连接外部网络。仓库为私有，需登录有访问权限的 GitHub 账号下载。预览包未代码签名，附件 SHA256 文件用于完整性校验。
