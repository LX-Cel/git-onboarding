# 0.2.0-preview.1 · Git 系统课程扩展

Windows x64 私有预览版。课程从 3 门扩展至 33 门，共 66 个引导/挑战场景，沿用 Fluent 2 工作台。

- 新增 rebase、交互式 rebase、冲突恢复、cherry-pick、stash、reflog。
- 新增 origin/upstream 双远端 Fork → 功能分支 → PR → 评审修改 → 合并与同步；托管流程在本地模拟，仓库和 Git 操作真实执行。
- 新增部分暂存、amend、三种 reset、worktree、bisect、标签、忽略规则、文件重命名。
- 新增推送拒绝、force-with-lease、远端修复、rebase --onto、autosquash、撤销合并、子模块、稀疏检出、浅克隆、补丁和 bundle。
- 课程支持按命令搜索和分类筛选；修复终端启动时输入竞态，课程更新验证文件内容。

## 安装和升级

下载本页 `Git-Onboarding-0.2.0-preview.1-Setup.exe`。关闭旧应用，安装到原目录，无需先卸载。启动后如提示课程更新，选择「保留练习并更新」。该操作更新课程程序，保留练习文件、提交历史、暂存区及进度。

安装包附带隔离练习环境；首次使用仍需 Windows WSL 2。预览包未签名。仓库为私有，需登录有访问权限的 GitHub 账号下载。附件 `SHA256SUMS-0.2.0-preview.1.txt` 可用于校验完整性。

## 范围

这是已完成课程的阶段性预览版，完整覆盖计划仍在推进。PR 保护规则与更多合并策略、LFS、签名及部分综合任务尚未包含。它不连接真实 GitHub 进行课程 PR 操作，也不支持自动更新桌面应用。
