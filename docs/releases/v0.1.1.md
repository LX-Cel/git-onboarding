# v0.1.1 · 提交判题与阅读体验修复

入门练习此前要求 README 中出现指定句子，导致正常提交自己的内容后仍无法完成。现在检查 README 的实际修改是否已提交，允许自由写内容；空提交、仅改提交说明、只保存或暂存仍不会完成。未通过的条件会显示具体原因。

- 正文、编辑器与终端默认 16px，按钮和导航 14px，辅助文字至少 12px；改善中文字体回退和文字对比度。
- 新增可记忆的 100%、125%、150%、200% 显示比例，并适配窄窗口布局。
- 课程更新保留原有文件、提交历史、暂存内容和学习进度。
- WSL 超时或服务故障不再误触发组件安装。

## 从 0.1.0 升级

1. 保存编辑器中的内容并关闭旧版应用。
2. 运行 `Git-Onboarding-0.1.1-Setup.exe`，安装到原位置。
3. 打开应用，点击「更新练习环境」，再点击「保留练习并更新」。
4. 进入原练习，点击「检查练习结果」。无需重新开始或重做已经完成的提交。

右上角可以调整字号。安装包已包含 Linux 镜像，普通使用者只需下载 exe；其他附件用于源码构建与校验。

## 验证与限制

六个真实 Git 场景、63 个断言、真实 PTY、源码及打包程序的桌面端到端测试、旧版课程升级保留数据测试通过。打包程序的测试数据路径包含空格和英文单引号。

Windows x64 私有试用版，安装包尚未签名。没有在用户当前安装上覆盖安装来验证 NSIS 升级；全新未安装 WSL 的机器等限制仍见仓库验收记录。仓库继续保持私有。
