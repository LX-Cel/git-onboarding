# 第二轮视觉方向

针对上一轮只有布局差异、视觉语言相近的问题，保持相同练习、相近页面结构和完成状态，比较三套配色、字形、边界和控件形态。使用内置 image_gen 生成，每版完整提示词保存在 prompts.json。当前为视觉概念，未替换应用界面。

| 方向 | 视觉特征 | 适用取舍 |
| --- | --- | --- |
| A 纸感书房 | 暖白、墨黑、陶土红；宋体标题；细边界与小圆角 | 安静、成人学习感强；落地时正文与控件改回黑体，避免图中宋体使用过多 |
| B 石墨实验室 | 炭黑、灰白、黄绿；硬朗黑体与等宽代码；方形控件 | 专业工具感最强；新手亲和感较弱 |
| C 友好练习册 | 浅紫白、葡萄紫、杏橙；圆润黑体；大圆角粗线图标 | 新手更友好；装饰程度应控制，正式实现减少图中的渐变与阴影 |

字体均为图像模型表现的风格意向，不代表已经加载或验证了指定字体。正式实现需验证中文字体授权与 Windows 渲染、正常缩放的可读性。拟定正文及代码 16px、辅助文字 14px、页面标题 28–32px，作为原型起点而非已验证结论。

三图均保留 README 编辑器、完整 Bash 终端、完成条件、提交证据、再次检查与下一关。图中模型添加的关闭、分屏等图标并不表示现有功能已经支持；正式实现按实际能力收敛。所有版式和字形仍需可运行原型验证。
